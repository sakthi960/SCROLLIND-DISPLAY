# Scrolling Display Using WS2812B LED Strip

An embedded systems project focused on developing a scrolling LED display using WS2812B individually addressable RGB LED strips.

## About the Project

This project demonstrates the implementation of a scrolling display using WS2812B addressable RGB LEDs.

The system uses an embedded controller to control LED patterns and display scrolling visual information.

WS2812B technology allows individual LEDs to be controlled through a digital data signal, making it suitable for creating programmable LED display systems.

## Working Principle

1. The embedded controller initializes the WS2812B LED strip.
2. Display data is processed by the controller.
3. LED colors and positions are updated using digital control signals.
4. The display pattern moves across the LED strip.
5. Repeated updates create a continuous scrolling display effect.
